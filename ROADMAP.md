# План розвитку: Додаток Обліку Меблів (ViyarApp)

Цей документ фіксує поточний стан та плани розвитку сервісу для меблевої бригади, оскільки цей проєкт є незалежним від корпоративної діяльності ViyarStone.

---

## ✅ Що вже зроблено (MVP)

1. **Канбан-дошка для управління проєктами**
   - Розроблено інтерактивний PWA-застосунок з колонками статусів (На погодженні, В очікуванні, В роботі, Потребує допрацювання, Виконано).
   - Адаптивний дизайн: мобільний (горизонтальний touch-скрол) та десктопний (Drag & Drop) інтерфейс.

2. **Облік деталей та фурнітури**
   - Вбудовано систему чек-листів для кожної картки-проєкту.
   - Стан чек-листів (виконано/не виконано, кількість) зберігається динамічно, без потреби перезавантажувати сторінку.
   - Кнопка "+ Додати" завжди доступна для користувачів з роллю Адмін.

3. **Базова архітектура та розгортання**
   - Налаштовано локальний Git-репозиторій.
   - Підготовлено інструкції для пушу коду на GitHub.
   - Повністю розділено Frontend (Vanilla JS + Tailwind CSS) та Backend.

---

## 🚧 Що планується далі (Backlog)

1. Розширення системи ролей (Адмін, Працівник тощо).
2. Підключення справжньої бази даних для збереження стану проєктів між різними пристроями.
3. Генерація розширених звітів щодо виконаних робіт та витрат фурнітури.
