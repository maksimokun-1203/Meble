# ViyarApp — Система обліку меблевого виробництва

Веб-застосунок для ведення проєктів, обліку модулів, креслень, виплат, рахунків ВіЯр та інтерактивного календаря планування (монтажі, збірки, заміри).

---

## 🚀 Як встановити та запустити на домашньому комп'ютері

### Крок 1. Клонування репозиторію з GitHub

Відкрийте термінал (PowerShell, Git Bash або Командний рядок) у потрібній папці:

```bash
git clone https://github.com/maksimokun-1203/Meble.git
cd Meble
```

*(Якщо проєкт вже було схилено раніше, просто виконайте `git pull`)*

---

### Крок 2. Швидкий запуск (В один клік)

Просто запустіть файл **`start_app.bat`** (подвійним кліком миші або через термінал):
- Скрипт автоматично перевірить Python.
- Створить віртуальне оточення `.venv`.
- Встановить необхідні пакети з `requirements.txt`.
- Перевірить та оновить базу даних.
- Запустить сервер та відкриє браузер за адресою **`http://127.0.0.1:8000/`**.

> Або для PowerShell: клацніть правою кнопкою на `start_app.ps1` -> *Run with PowerShell*.

---

### Крок 2 (альтернативний). Ручний запуск

1. Створіть та активуйте віртуальне оточення:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Перейдіть до папки `backend` та запустіть сервер:
   ```bash
   cd backend
   python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
   ```
4. Відкрийте у браузері: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
